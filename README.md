Binance WS-shaped paper feed — stub trades.

## Features

- Venue binance / BTCUSDT
- Strategy ws
- Paper backtest, fee model, node:test

## Prerequisites

- Node.js 20+
- Git

## Getting Started

```bash
git clone <repo-url>
cd binance-ws-feed
npm install typescript --no-save
npm run build
node dist/cli.js --help
```

## Tests

```bash
node --experimental-strip-types --test tests/*.test.ts
```

## CLI

```bash
node --experimental-strip-types src/cli.ts --help
```
